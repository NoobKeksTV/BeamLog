# BeamLog 1.0.3

Zusammenfassung aller Neuerungen seit 1.0.0 (die Zwischenstände 1.0.1 und 1.0.2 hatten keine Windows-Version):

- **Große Startdatenbank:** 6.326 Stationen mit Locator, davon 3.883 mit DOK. Neue Installationen haben sie sofort;
  bestehende holen sie über *Verwaltung → Stationsdatenbank → „Nach neuen suchen (Repo)“*.
- **Log-Prüfung:** Klick auf einen Befund öffnet das QSO mit dem Korrekturvorschlag bereits eingetragen (gelb markiert),
  dann „Änderungen speichern“ – die Prüfung öffnet sich danach wieder. RST mit führender Null (059) ist kein Fehler mehr
  und wird still zu 59 korrigiert.
- **Flugzeug-Höhenprofil** mit Legende (Mindesthöhe, Zone, Farben).
- **Server (Debian/Raspberry Pi):** Der Port aus `/etc/beamlog/beamlog.env` gilt jetzt immer – `PORT=80` läuft direkt ohne
  nginx, jeder andere Port hinter nginx. Nur noch eine Dienst-Unit; `install.sh` bricht nicht mehr ab und übernimmt
  Port/Adresse aus älteren Units. Danach einfach `sudo bash deploy/install.sh --update`.
- Verständliche Meldung, wenn der Port belegt ist; Kommentare hinter Werten in `beamlog.env` erlaubt.
