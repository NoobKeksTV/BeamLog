# BeamLog 1.0.1

🎬 [Video „BeamLog in 1:42 Minuten“ auf YouTube](https://youtu.be/yvYb6FNvjzA) · 🧪 [Live-Demo ausprobieren](https://beamlogdemo.lhprinting.de/) (Passwort `demo`) · 📖 [Wiki](https://github.com/NoobKeksTV/BeamLog/wiki)

## Das Wichtigste in Kürze

- **Einstellungsdatei heißt jetzt `.env`** (Vorlage `.env.example`). Eine vorhandene `beamlog.env` wird beim Start bzw.
  von `install.sh --update` automatisch umbenannt – es geht nichts verloren.
- **Server: alles in einem Ordner.** Programm, Daten (`data/`) und Einstellungen (`.env`) liegen jetzt zusammen in
  `/opt/beamlog`. `sudo bash deploy/install.sh --update` holt eine bestehende Installation automatisch aus
  `/var/lib/beamlog` und `/etc/beamlog` dorthin (die alten Daten bleiben als Sicherung liegen) – Schluss mit
  verstreuten Rechten.
- **Install-Skript mit Optionen:** `--no-nginx`, `--no-service`, `--no-backup` (kombinierbar und gemerkt),
  `--deps-only` (nur Python & Co. installieren), `--here` (im aktuellen Ordner bleiben). Ohne Dienst wird nichts
  mehr nach `/opt` kopiert; mit Dienst sagt das Skript deutlich, dass und warum es kopiert.
- **Robuster Start:** fehlende Ordner und Vorlagen werden selbst angelegt, fehlende Schreibrechte verständlich erklärt;
  `python run.py` nimmt automatisch die virtuelle Umgebung `.venv`, `start.sh`/`start.bat` halten die Pakete aktuell.
- **Demo-Modus** (`DEMO=1`) für öffentliche Vorführ-Instanzen – feste Zugangsdaten, gesperrte Server-Funktionen,
  tägliches Zurücksetzen auf einen Beispiel-Contest.
- **Ergebnislisten-Archiv** (Betreuer-Modus): Ergebnislisten und Einzel-Logs von DARC (UKW/KW) und IARU Region 1
  über alle Jahre, mehrere Listen parallel und rund dreimal schneller.
- **Wiki** jetzt auch im GitHub-Reiter „Wiki“.

**Update:** Portable Version über Verwaltung → Updates oder neues ZIP entpacken. Server: neues Linux-ZIP entpacken und
`sudo bash deploy/install.sh --update`.
